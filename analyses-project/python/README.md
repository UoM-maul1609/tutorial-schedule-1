## The important idea
The notebook is a **toolbox, not a checklist**. Explore the core analyses, then choose one aspect of ENSO and cloud cover that interests you. Your short report should answer one focused question using about **3–5 figures**, not reproduce every notebook output.

Possible directions include cloud level, region, season, persistence or lag.

## Data
- ERA5 atmospheric data — ECMWF / Copernicus Climate Change Service.
- ONI — NOAA Climate Prediction Center.
- Large ERA5 NetCDF files are supplied separately and should be placed in `era5_monthly_nc/`.

Figures you generate are your own figures, but acknowledge/cite the underlying datasets.
